# Security Policy

## Supported Versions

We currently support the latest major release of ShadowPlane for security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of ShadowPlane seriously. If you believe you have found a security vulnerability, please report it to us confidentially.

**DO NOT create a public GitHub issue for security vulnerabilities.**

Instead, please email **syedaamairshareef@gmail.com* with:
1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. The impact of the vulnerability.

We will acknowledge your report within 48 hours and provide a timeline for triage and resolution.

## AI & Agentic Security

ShadowPlane intercepts AI-generated infrastructure code. If you discover a bypass mechanism where a malicious or hallucinating AI agent can escape the LocalStack sandbox and provision real AWS resources, please report this immediately as a **Critical** vulnerability.
